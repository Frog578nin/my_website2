Сайт, который вы читаете, сам по себе учебный проект по курсу веб-технологий. Задача: сделать персональный академический сайт с резюме, блогом и ссылками на научные профили и опубликовать его по-взрослому.

Он собран на Hugo, генераторе статических сайтов, на шаблоне Academic CV. Весь контент — файлы Markdown и YAML в открытом репозитории на GitHub. На каждый пуш GitHub Actions пересобирает сайт и выкладывает его на GitHub Pages, так что публикация поста — это один `git push` и никаких ручных загрузок.

Чему я научился, пока его делал: Git глубже азов, Markdown, YAML-конфиги с их беспощадными отступами, устройство пайплайнов GitHub Actions и то, как в Hugo работает многоязычная маршрутизация, ведь весь сайт существует на русском и английском.
