Консольный тренажёр карточек, который я написал в выпускном классе для подготовки к экзаменам и до сих пор использую для университетской терминологии.

Карточки хранятся в JSON-файле парами «вопрос — ответ», разложенными по колодам. Тренажёр показывает случайную карточку, ждёт ответа, а карточки с ошибками складывает в стопку повторения, которая выпадает чаще. Это упрощённая версия интервального повторения. Прогресс сохраняется между запусками.

Внутри чистый Python без внешних зависимостей: только стандартная библиотека, около трёхсот строк. На нём я разобрался с работой с файлами, с JSON и с разницей между кодом, который работает, и кодом, который можно прочитать через месяц. В первой версии была функция `do_stuff2`. В нынешней такой нет.
