# Персональный сайт — Кирилл Челухаев

Личный академический сайт, сделанный в рамках учебного проекта по веб-технологиям.
Собирается генератором статических сайтов Hugo на теме Academic CV (Hugo Blox),
публикуется на GitHub Pages.

**Сайт:** https://frog578nin.github.io/my_website2/
(английская версия — по основному адресу, русская — на `/ru/`)

## Что на сайте

- Профиль: фотография, биография, интересы, образование.
- Опыт, навыки, достижения и владение языками — страница `/experience/`.
- Ссылки на научные и библиометрические ресурсы: eLibrary, Google Scholar,
  ORCID, Mendeley, ResearchGate, Academia.edu, arXiv, GitHub.
- Блог: недельные заметки об учёбе и тексты об инструментах — Git, Markdown,
  BibTeX, языки научного программирования, генераторы статических сайтов.
- Раздел проектов.
- Полностью двуязычный: весь контент и интерфейс на русском и английском.

## Как устроен репозиторий

| Путь | Что внутри |
| --- | --- |
| `content/` | Контент сайта в Markdown. Файл `index.md` — английская версия, `index.ru.md` — русская |
| `content/blog/` | Посты, по папке на пост |
| `content/projects/` | Записи о проектах |
| `data/authors/me.yaml` | Профиль: биография, образование, опыт, навыки, достижения, ссылки |
| `data/ru/authors/me.yaml` | Русский перевод профиля, накрывает поля из английского |
| `config/_default/` | Настройки Hugo: адрес сайта, языки, меню, оформление |
| `i18n/ru.yaml` | Русские переводы элементов интерфейса |
| `assets/media/authors/` | Фотография владельца сайта |
| `.github/workflows/` | Сборка и публикация через GitHub Actions |

## Локальный запуск

Нужны [Hugo extended](https://gohugo.io/installation/) (версия указана в
`hugoblox.yaml`), Node.js и pnpm.

```bash
pnpm install
pnpm run dev
```

Сайт откроется на http://localhost:1313/my_website2/ и будет пересобираться
при каждом сохранении файла.

Собрать статические файлы в папку `public/`:

```bash
pnpm run build
```

## Публикация

Каждый пуш в ветку `main` запускает workflow `.github/workflows/deploy.yml`:
GitHub Actions собирает сайт и выкладывает его на GitHub Pages. Вручную ничего
загружать не нужно.

## Как добавить пост

Создать папку в `content/blog/`, положить туда `index.md` (английская версия) и
`index.ru.md` (русская). Начало файла — метаданные:

```yaml
---
title: 'Заголовок поста'
summary: Короткое описание для карточки в списке.
date: 2026-09-03
authors:
  - me
tags:
  - Заметки недели
---
```

Дальше — текст поста в Markdown.
